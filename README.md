# Traderz Desk

Intern prototype af en handelsplatform for el i DK1 og DK2.

## Indhold
- `index.html` – hele applikationen (HTML, CSS og JavaScript i én fil)
- `netlify.toml` – opsætning til hosting på Netlify

## Status
- Priser og vejr er simulerede. Der er ingen forbindelse til Nord Pool eller Energinet endnu.
- Handler gemmes kun i den enkelte browser (localStorage).

## Næste skridt
- Rigtige priser fra Energinets Energi Data Service via en backend
- Database til handler, så data deles mellem brugere og enheder
- Login
- Understøttelse af 15-minutters perioder i day-ahead-markedet

## Kør lokalt
Åbn `index.html` direkte i en browser. Der kræves ingen installation.
